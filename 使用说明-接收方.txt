APIOne 批量调用工具 · 接收方使用说明
====================================

一、怎么启动
  1. 把压缩包**整个解压**到任意目录（桌面、「下载」都可以）。
     必须整目录解压，不能只从压缩包里单独拖出某个文件，否则会缺运行时。
  2. macOS：双击「启动_APIOne批量工具.command」。
  3. 本包已内置 Python 运行时，你不需要自己安装 Python。

二、如果双击打不开（macOS 常见）
  系统会拦一次「来自身份不明的开发者」，这是压缩包从网络传过来的正常反应，
  不是文件坏了。按下面任一方式放行：

  · 右键点「启动_APIOne批量工具.command」→ 选「打开」→ 弹窗里再点一次「打开」。
    （只需做一次，之后双击即可。）

  · 如果双击直接闪退、或提示「无法打开」，打开「终端」执行下面两行
    （第二行的路径换成你实际解压出来的目录）：

        cd "你解压出来的目录"
        chmod +x 启动_APIOne批量工具.command 启动_APIOne批量工具.sh && xattr -dr com.apple.quarantine .

    然后重新双击即可。

三、启动前需要准备的：Java
  本工具调用接口需要 **JDK 17 或更高版本**（内部桥接程序按 JDK 17 编译）。
  在「终端」执行下面这条命令查看：

        java -version

  · 看到 17 及以上（例如 17.0.x / 21.x）→ 已满足，可以直接用。
  · 提示 command not found，或版本低于 17 → 任选一种方式安装：

        brew install --cask temurin17

    或者到 Adoptium / Microsoft OpenJDK 官网下载安装包。装完重新打开本工具。

  不确定也没关系：打开工具后点右上角「环境检查」，它会逐项告诉你缺什么。

四、第一次调用怎么做
  1. 左侧点「新建任务」。
     「请求地址」「API Name」和 id 参数已经预填好，正常情况下不用改。
  2. 填上接口提供方给你的 AK、SK，点「保存任务」。
     （凭据本包不包含，需要另外索取，请勿写进聊天记录或截图分享。）
  3. 点「执行一次（测试）」——只发 1 次请求，用来确认链路是否打通。
  4. 结果看右侧「动态日志」页。接口返回的原始内容会写到
     results/<任务ID>.jsonl，一行对应一次调用，方便你逐条核对。

五、常见问题
  · 提示找不到 Java 或版本过低
      按第三节装 JDK 17，然后重新打开工具（不用重启电脑）。
  · 提示 AK/SK 未填
      在「接口与鉴权」页补上，再点「保存任务」。
  · 执行后一直失败
      先确认这台电脑能访问请求地址（浏览器能打开网关域名即可），
      再点「动态日志」看具体报错；接口本身返回失败时，日志里会带上
      requestId，可以拿这个找接口提供方排查。
  · 想知道环境到底齐不齐
      点右上角「环境检查」，Python 运行时 / Java / SDK JAR / 桥接程序 /
      目录权限五项会逐条列出。

六、本地会写入哪些文件
  data/tasks.json     任务配置（不含 AK/SK）
  data/secrets.json   AK/SK 单独存放，权限 600，只有本机当前用户可读
  logs/               每次任务的运行日志
  results/            每次调用的返回结果（JSON Lines）
  update/             版本更新时下载的临时文件
  这些目录在你点「检查更新」或手动升级时都会被保留，不会被覆盖。
